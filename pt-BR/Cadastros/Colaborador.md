

# Como cadastrar colaboradores no Símix Ponto

## Objetivo

Neste artigo, você aprenderá a realizar o cadastro de colaboradores no sistema Símix Ponto, garantindo que os dados estejam corretos para integração com relógios e folha de pagamento.

## Pré-requisitos

Antes de começar, verifique se você possui:
- Acesso ao sistema Símix Ponto com privilégio para cadastro.
- Informações do colaborador (CPF, PIS, data de admissão, cargo entre outros que desejar). 
- Código da folha de pagamento (se sua empresa utiliza integração).

## Passo a Passo

### 1. Acesse o menu de cadastro


No Símix Ponto, vá até Cadastro > Colaboradores e clique em Novo para iniciar o cadastro.

- Ao clicar em Novo, o sistema gera automaticamente um código sequencial para identificar o funcionário.
  
**Importante:** Não recomendamos alterar esse código posteriormente, pois ele é usado para registro de ponto e integrações. 

**Dica:** Se sua empresa utiliza o mesmo código da folha de pagamento, em vez de clicar em Novo, digite esse código diretamente no campo Código e também em Código da folha para manter igual.
Caso o código já esteja sendo utilizado, não poderá ser reaproveitado.


### Preencha a Guia Principal

Esta guia contém os dados obrigatórios para identificação do colaborador e integração com relógios e folha de pagamento.

_**Os principais campos a serem preenchidos são:**_

- **Código**: Identificação única do colaborador no Símix (usado também para registro de ponto).
- **Nome:** Será exibido no espelho do cartão ponto e relatórios.
- **Gênero:** Esta informação é utilizada para identificação interna, emissão de relatórios e atendimento a requisitos legais de vínculos trabalhistas.
- **CPF:** Obrigatório para atender à Portaria 671 e o colaborador poder utilizar a plataforma em registros e consultas.
- **PIS:** Obrigatório para atender à Portaria 1510, se utilizado equipamento correspondente.
- **Código na folha:** Código usado no sistema de folha de pagamento.
- **Dt. Nascimento:** Data de nascimento (Carrega na lista de aniversariantes, o sistema exibirá parabéns no aniversário).
- **Dt. Admissão:** Fundamental para estabelecer início de contagem do cartão ponto , controle de tempo de empresa e contratos.
- **Cargo, nível de cargo, Departamento, Setor e Seção:** Para filtros em relatórios.
- **Tipo:* Mensalista, estagiário ou horista.
- **Horário:** Selecione um quadro de horários previamente cadastrado.
- **Estabelecimento:** Define onde o colaborador está alocado.
- **Matrícula:** Número da matrícula do colaborador. (Opcional)

### 3. Documentos

- **Carteira de Trabalho:** Informe o número da carteira.
- **Código externo:** para integração com outros sistemas
- **Contrato:** permite calcular término automático de contratos
- **RG:** dado complementar para relatórios internos
- **Nome social:** substitui o nome civil em sistemas e aplicativos
- **Pronúncia:** registra a forma correta de pronúncia

### 4. Complementar

- **Pronúncia:** forma correta de pronunciar o nome do colaborador.
- **Email:** E-mail principal do colaborador.
- **Email alt.:** E-mail alternativo para comunicação.
- **Telefone:** Número de telefone para contato.
- **Valor salário:** Valor do salário mensal do colaborador. 
- **Valor hora:** Valor pago por hora trabalhada.
- **Estado civil:** Selecione o estado civil do colaborador.
- **Escolaridade:** Nível de escolaridade do colaborador.
- **Situação:** Situação da escolaridade (Incompleto, Cursando ou Completo).
- **N. armário:** Número do armário vinculado ao colaborador (se aplicável).
- **Observações:** Campo livre para registrar informações adicionais.

### 5. Endereço 

Utilize esse campo como uma base de dados sobre informações pessoais do colaborador. O endereço é importante em diversas questões de controle como vale transporte e informações oficiais como e-social 

- **Digite o CEP:** Preencha o CEP do local. Quando informado corretamente, alguns dados podem ser sugeridos automaticamente pelo sistema. 
- **Preencha o Endereço:** Informe o nome da rua, avenida, travessa ou qualquer logradouro correspondente ao local. 
- **Adicione o Complemento:** Utilize este campo para inserir detalhes adicionais, como bloco, torre, número do apartamento, sala ou outras referências importantes. 
- **Informe o Bairro:** Preencha o bairro ou selecione-o utilizando a lupa disponível ao lado do campo.  
- **Informe a Cidade:** Digite a cidade do endereço ou busque utilizando a lupa.
