# Como criar seu usuário no Símix Ponto


## 🎯Objetivo
Neste artigo, você aprenderá como criar seu usuário de acesso ao Símix Ponto. Esse processo é essencial para entrar na plataforma e utilizar os recursos liberados para o seu perfil


## Pré-requisitos
Antes de começar, verifique se você possui:
- Cadastro de colaborador ativo com CPF registrado
- Link de acesso ao Símix Ponto fornecido pela sua empresa


### Passo a Passo para criar seu usuário

1. Acesse a tela inicial do Símix Ponto pelo link encaminhado pela empresa. 
2. Clique em Registrar-se. 
3. Insira um nome de usuário.
- Você pode utilizar um padrão simples, como joao.silva. 

4. Digite o seu e-mail. 
5. Confirme o e-mail repetindo-o no campo correspondente. 
6. Informe o seu CPF. 
7. Crie uma senha de acesso. 
8. Clique em Registrar-se para finalizar o cadastro. 
9. Após registrar-se, faça login utilizando o usuário ou e-mail cadastrado e a senha que você criou. 

Pronto! Agora você já terá acesso aos menus liberados para o seu perfil de usuário.

### Solução de Problemas

#### Erro ao confirmar o CPF?
- Verifique, junto ao responsável da sua empresa, se o cadastro de colaborador já foi criado corretamente no sistema.
  
#### Esqueceu a senha? 🤔
- Localize na tela inicial o campo esqueceu a senha, você receberá um email com link para recuperação.
- Você também pode procurar seu administrador de sistema e solicitar uma senha temporária
